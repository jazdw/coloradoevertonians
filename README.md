# Colorado Evertonians

Static website for the Colorado Evertonians, the Everton supporters club for Colorado. Hosted on Cloudflare Workers: static assets from `public/`, plus a small Worker (`src/worker.js`) for `/api/*` routes.

## Local development

```sh
npm install
npm run dev      # http://localhost:8787
```

Site files live in `public/`. For the fixtures list, create a `.dev.vars` file (gitignored) with the iCal feed URL:

```sh
FIXTURES_ICS_URL=https://example.com/team.ics
```

## Deployment

Every push to `main` deploys automatically via `.github/workflows/deploy.yml`. The repo needs these GitHub Actions secrets:

- `CLOUDFLARE_API_TOKEN`: create one at https://dash.cloudflare.com/profile/api-tokens using the **Edit Cloudflare Workers** template
- `CLOUDFLARE_ACCOUNT_ID`: shown on the Workers & Pages overview in the Cloudflare dashboard

Manual deploy: `npm run deploy`.

The Worker also needs the `FIXTURES_ICS_URL` secret set on Cloudflare (once): `npx wrangler secret put FIXTURES_ICS_URL`. Without it, the "Next matches" list is hidden.

## Future features

Contact form: add another route (e.g. `/api/contact`) to `src/worker.js`.

## Design motif

The cross-braced band (`public/truss.svg`) is drawn after Archibald Leitch's balcony truss at Goodison Park. It's generated by `scripts/gen_truss.py`; tweak the proportions there and re-run it rather than editing the SVG by hand.
