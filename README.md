# Colorado Evertonians

Static website for the Colorado Evertonians, the Everton supporters club for Colorado. Hosted on Cloudflare Workers (static assets only).

## Local development

```sh
npm install
npm run dev      # http://localhost:8787
```

Site files live in `public/`.

## Deployment

Every push to `main` deploys automatically via `.github/workflows/deploy.yml`. The repo needs these GitHub Actions secrets:

- `CLOUDFLARE_API_TOKEN`: create one at https://dash.cloudflare.com/profile/api-tokens using the **Edit Cloudflare Workers** template
- `CLOUDFLARE_ACCOUNT_ID`: shown on the Workers & Pages overview in the Cloudflare dashboard

Manual deploy: `npm run deploy`.

## Future features

Events calendar or contact form: add a `main` Worker script in `wrangler.jsonc` to handle API routes (e.g. `/api/contact`) alongside the static assets.

## Design motif

The cross-braced band (`public/truss.svg`) is drawn after Archibald Leitch's balcony truss at Goodison Park. It's generated by `scripts/gen_truss.py`; tweak the proportions there and re-run it rather than editing the SVG by hand.
